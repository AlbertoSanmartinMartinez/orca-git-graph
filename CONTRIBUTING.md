# Contributing

Bug reports, documentation improvements, and compatibility testing are welcome. Start with the installation guide and architecture document, then open an issue or pull request describing the concrete behavior you want to change.

Run the core and browser checks listed in `AGENTS.md`. Use temporary Git repositories for tests and fictional histories for screenshots. Keep the runtime dependency-free beyond Python 3.9+ and Git.

For Orca compatibility reports, include the exact Orca version, OS, how the plugin was registered, and whether project switching and Development reload work. Automated Python tests on an operating system do not establish desktop integration support.

Keep public content in English. Never include private repository snapshots, access tokens, Orca profile files, or personal filesystem paths in a pull request. See `SECURITY.md` for reporting security problems.
